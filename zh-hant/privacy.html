隱私權政策

生效日期：2026年10月24日

我們不會收集任何能識別你身分的資料。Pixel Home 在我們這端沒有帳號，也沒有追蹤，我們也沒有為它運作任何伺服器。從 1.1 版開始，遊戲會顯示廣告。廣告由 Google 提供，為此 Google 會從你的裝置接收部分資訊；以下關於廣告的段落會說明接收哪些資訊、在什麼時候，以及你可以做哪些選擇。從 1.2 版開始，遊戲也會傳送匿名遊玩統計資料，你可以將它關閉；相關段落會說明其中包含哪些內容。

留在你裝置上的資料

你的進度和設定儲存在你的裝置上。你的生命、購買所獲得內容的紀錄，以及你的登入資訊，都保存在你裝置上的 iOS 鑰匙圈中；即使刪除遊戲，這些資料仍可能保留，好讓你重新安裝時它們還在。這些資料都不會傳送給我們。

使用 Apple 登入（可選）

你可以用訪客身分遊玩。如果你選擇登入，遊戲只會向 Apple 要求你的姓名，絕不會要求你的電子郵件地址。Apple 會提供遊戲一個代表你帳號的識別碼。它保存在你的裝置上，用來標示你自己 iCloud 儲存空間中的存檔。我們沒有伺服器，所以識別碼和你的姓名都不會傳到我們這裡。

iCloud 存檔

登入後，你的進度會儲存到你自己的 iCloud 鍵值儲存空間，以便跟著你到其他裝置上。該儲存空間屬於你的 Apple 帳號，我們無法讀取。Apple 對它的處理方式受 Apple 隱私權政策規範。

Game Center（可選）

如果你選擇登入 Game Center，你的分數和成就會以你的 Game Center 個人檔案傳送到 Apple 的 Game Center。在你要求之前，遊戲不會啟動 Game Center。

購買項目

App 內購買由 Apple 處理。我們絕不會看到你的付款資料。

廣告

從 1.1 版開始，Pixel Home 會顯示兩種廣告，都由 Google AdMob 提供：每通過五個關卡後出現的全螢幕廣告，以及你可以選擇觀看以換取一條額外生命的影片。關卡進行中絕不會出現廣告。1.0 版不顯示廣告，也不包含任何廣告軟體。在第一次需要廣告之前，也就是在你要求觀看影片時，或在關卡之間的第一則廣告出現前不久，不會有任何資料傳送給 Google。

Google 會收到哪些資訊

為了投放廣告、限制廣告出現的頻率並評估廣告成效，遊戲中的 Google 廣告軟體會傳送以下資訊給 Google，例如你的 IP 位址（可看出你的大概位置）、裝置和 App 的詳細資訊（機型、系統版本、語言、App 版本）、為此 App 保存在你裝置上的識別碼，以及廣告是否已顯示或被點選。這些資訊會傳送給 Google 及其廣告合作夥伴，而不是我們。Google 如何使用採用其服務的應用程式中的資訊說明了 Google 會如何使用這些資訊，以及你可以如何控管。

不使用個人化廣告，以及你的選擇

遊戲一律要求非個人化廣告。遊戲絕不會要求在其他公司的 App 和網站間追蹤你的權限，因此不會使用你的廣告識別碼。不過，廣告仍可能依一般情境挑選，例如你的大概位置、語言和你正在使用的 App。如果你位於歐洲經濟區、英國或瑞士，Google 的同意聲明表單會在第一則廣告前詢問你的選擇，並列出相關的廣告合作夥伴。你可以拒絕，也可以隨時在遊戲的設定中，點廣告選項更改你的選擇。

匿名遊玩統計資料

從 1.2 版開始，Pixel Home 會將匿名遊玩統計資料傳送給分析服務 PostHog：哪些關卡被開始、通過或放棄、生命何時用完、商店何時被打開、購買如何結束，以及 App 版本和遊戲語言。其中不包含姓名、帳號、廣告識別碼或裝置識別碼，也不包含任何能識別你身分的內容：每天都會更換的隨機值，讓我們能計算每天的玩家人數，卻無法在不同日子之間認出任何人。這些資料儲存在歐盟境內，不含 IP 位址或位置資訊。你可以在遊戲的設定中，關閉分享匿名遊玩統計資料。PostHog 的處理方式受 PostHog 隱私權政策規範。

兒童

我們不會收集任何能識別任何人身分的資料，兒童也不例外：遊玩統計資料是匿名的。廣告絕不會個人化，並僅限於 Google 評定為適合所有觀眾的廣告。

本網站

本網站由 GitHub Pages 代管。本網站不使用 Cookie，也沒有自己的分析工具。GitHub 可能會為了營運服務而記錄 IP 位址等技術資訊，詳見 GitHub 隱私權聲明。從 1.1 版開始，遊戲啟動時也會從本網站讀取一個小型設定檔，以便減少顯示廣告，或告知有新版本可用。這項請求不包含任何關於你的資訊，但就像任何造訪一樣，GitHub 可能會記錄請求來源的 IP 位址。你也可以在本網站上用瀏覽器玩遊戲。這時，遊戲會把你的進度保存在你裝置上的瀏覽器儲存空間中，不會把任何關於你或你遊玩情形的資訊傳送給我們或其他任何人。

變更

如果本政策有所變更，新版本會連同新的生效日期一起公布在此頁面上。

翻譯版本

為方便起見，本政策以多種語言發布。如各版本內容有所不同，以英文版本為準。
