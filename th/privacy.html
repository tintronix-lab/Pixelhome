นโยบายความเป็นส่วนตัว

มีผลบังคับใช้ตั้งแต่วันที่ 27 ตุลาคม 2569

เราไม่เก็บรวบรวมข้อมูลใดๆ ที่ระบุตัวตนของคุณได้ Pixel Home ไม่มีบัญชีผู้ใช้ในระบบของเราและไม่มีการติดตาม และเราไม่ได้ดำเนินการเซิร์ฟเวอร์ใดๆ สำหรับเกมนี้ ตั้งแต่เวอร์ชัน 1.1 เกมจะแสดงโฆษณา โฆษณาเหล่านี้นำส่งโดย Google ซึ่งได้รับข้อมูลบางส่วนจากอุปกรณ์ของคุณเพื่อการนั้น หัวข้อเกี่ยวกับการโฆษณาด้านล่างอธิบายว่า Google ได้รับข้อมูลใด เมื่อใด และคุณเลือกอะไรได้บ้าง ตั้งแต่เวอร์ชัน 1.2 เกมยังส่งสถิติการเล่นแบบไม่ระบุตัวตน ซึ่งคุณปิดได้ หัวข้อเกี่ยวกับสถิติดังกล่าวอธิบายว่าสถิติมีข้อมูลอะไรบ้าง

สิ่งที่เก็บไว้บนอุปกรณ์ของคุณ

ความคืบหน้าและการตั้งค่าของคุณจัดเก็บไว้บนอุปกรณ์ของคุณ หัวใจของคุณ บันทึกรายการที่คุณได้รับจากการซื้อ และข้อมูลการลงชื่อเข้าของคุณ จัดเก็บไว้ในพวงกุญแจของ iOS บนอุปกรณ์ของคุณ ซึ่งข้อมูลเหล่านี้อาจยังคงอยู่ที่นั่นหลังจากลบเกมไปแล้ว เพื่อให้ข้อมูลยังคงอยู่หากคุณติดตั้งเกมอีกครั้ง ไม่มีข้อมูลใดในส่วนนี้ถูกส่งมาให้เรา

ลงชื่อเข้าด้วย Apple (ไม่บังคับ)

คุณเล่นในฐานะผู้เยี่ยมชมได้ หากคุณเลือกลงชื่อเข้า เกมจะขอเพียงชื่อของคุณจาก Apple และไม่ขอที่อยู่อีเมลของคุณเลย Apple จะให้ตัวระบุสำหรับบัญชีของคุณแก่เกม ตัวระบุนี้จัดเก็บไว้บนอุปกรณ์ของคุณ และใช้เพื่อติดป้ายกำกับข้อมูลเกมที่บันทึกไว้ของคุณในพื้นที่จัดเก็บ iCloud ของคุณเอง เราไม่มีเซิร์ฟเวอร์ ทั้งตัวระบุและชื่อของคุณจึงไม่มีวันมาถึงเรา

การบันทึกเกมใน iCloud

เมื่อคุณลงชื่อเข้าอยู่ ความคืบหน้าของคุณจะถูกบันทึกไว้ในพื้นที่จัดเก็บแบบคีย์-ค่าใน iCloud ของคุณเอง เพื่อให้ตามไปยังอุปกรณ์เครื่องอื่นของคุณได้ พื้นที่จัดเก็บนั้นเป็นของบัญชี Apple ของคุณ เราไม่สามารถอ่านข้อมูลในนั้นได้ การจัดการข้อมูลดังกล่าวของ Apple อยู่ภายใต้นโยบายความเป็นส่วนตัวของ Apple

Game Center (ไม่บังคับ)

หากคุณเลือกลงชื่อเข้า Game Center คะแนนและความสำเร็จของคุณจะถูกส่งไปยัง Game Center ของ Apple ภายใต้โปรไฟล์ Game Center ของคุณ เกมจะไม่เริ่มใช้งาน Game Center จนกว่าคุณจะขอ

การซื้อ

การซื้อภายในแอปดำเนินการโดย Apple เราไม่เคยเห็นข้อมูลการชำระเงินของคุณ

การโฆษณา

ตั้งแต่เวอร์ชัน 1.1 Pixel Home แสดงโฆษณา 2 ประเภท ซึ่งทั้งสองประเภทนำส่งโดย Google AdMob ได้แก่ โฆษณาเต็มหน้าจอหลังจากคุณผ่านด่านครบทุก 5 ด่าน และวิดีโอที่คุณเลือกดูได้เพื่อรับหัวใจเพิ่ม 1 ดวง โฆษณาจะไม่ปรากฏขึ้นระหว่างการเล่นด่านเลย เวอร์ชัน 1.0 ไม่แสดงโฆษณาและไม่มีซอฟต์แวร์โฆษณาใดๆ จะไม่มีสิ่งใดถูกส่งไปยัง Google จนกว่าจะต้องใช้โฆษณาเป็นครั้งแรก กล่าวคือ เมื่อคุณขอดูวิดีโอ หรือไม่นานก่อนโฆษณาแรกระหว่างด่าน

ข้อมูลที่ Google ได้รับ

เพื่อนำส่งโฆษณา จำกัดความถี่ในการแสดงโฆษณา และวัดผลโฆษณา ซอฟต์แวร์โฆษณาของ Google ในเกมจะส่งข้อมูลให้ Google เช่น ที่อยู่ IP ของคุณ (ซึ่งบ่งบอกตำแหน่งโดยประมาณของคุณ) รายละเอียดของอุปกรณ์และแอป (รุ่น เวอร์ชันของระบบ ภาษา เวอร์ชันของแอป) ตัวระบุที่จัดเก็บไว้สำหรับแอปนี้บนอุปกรณ์ของคุณ และข้อมูลว่ามีการแสดงหรือแตะโฆษณาหรือไม่ ข้อมูลนี้ส่งไปยัง Google และพันธมิตรด้านโฆษณาของ Google ไม่ได้ส่งมาให้เรา วิธีที่ Google ใช้ข้อมูลจากแอปที่ใช้บริการของ Google อธิบายว่า Google ทำอะไรกับข้อมูลนี้ และคุณควบคุมข้อมูลนี้ได้อย่างไร

ไม่มีโฆษณาเฉพาะบุคคล และตัวเลือกของคุณ

เกมจะขอโฆษณาแบบไม่เฉพาะบุคคลเสมอ เกมไม่ขออนุญาตติดตามคุณข้ามแอปและเว็บไซต์ของบริษัทอื่นเลย ตัวระบุสำหรับการโฆษณาของคุณจึงไม่ถูกนำมาใช้ โฆษณาอาจยังคงถูกเลือกตามบริบททั่วไป เช่น ตำแหน่งโดยประมาณของคุณ ภาษาของคุณ และแอปที่คุณกำลังใช้ หากคุณอยู่ในเขตเศรษฐกิจยุโรป สหราชอาณาจักร หรือสวิตเซอร์แลนด์ แบบฟอร์มขอความยินยอมของ Google จะขอให้คุณเลือกก่อนโฆษณาแรก และแสดงรายชื่อพันธมิตรด้านโฆษณาที่เกี่ยวข้อง คุณปฏิเสธได้ และเปลี่ยนคำตอบได้ทุกเมื่อในเกม ที่ การตั้งค่า แล้วเลือก ตัวเลือกโฆษณา

สถิติการเล่นแบบไม่ระบุตัวตน

ตั้งแต่เวอร์ชัน 1.2 Pixel Home ส่งสถิติการเล่นแบบไม่ระบุตัวตนไปยัง PostHog ซึ่งเป็นบริการวิเคราะห์ข้อมูล ได้แก่ ข้อมูลว่าด่านใดมีการเริ่มเล่น ผ่าน หรือยอมแพ้ หัวใจหมดเมื่อใด ร้านค้าถูกเปิดเมื่อใด และการซื้อสิ้นสุดลงอย่างไร พร้อมด้วยเวอร์ชันของแอปและภาษาของเกม ตั้งแต่เวอร์ชัน 1.4 สถิติยังรวมถึงว่าโฆษณาถูกดูจนจบ ถูกปิดก่อนจบ หรือไม่มีให้แสดง และจำนวนวันที่คุณเล่นโดยประมาณเป็นช่วง เช่น 2–3 หรือ 8–30 วัน สถิติเหล่านี้ไม่มีชื่อ บัญชี ตัวระบุสำหรับการโฆษณา หรือตัวระบุอุปกรณ์ และไม่มีสิ่งใดที่ระบุตัวตนของคุณได้ ค่าสุ่มที่เปลี่ยนไปทุกวันช่วยให้เรานับจำนวนผู้เล่นในแต่ละวันได้ โดยไม่จดจำผู้ใดข้ามจากวันหนึ่งไปอีกวันหนึ่ง สถิติเหล่านี้จัดเก็บในสหภาพยุโรป โดยไม่มีที่อยู่ IP หรือข้อมูลตำแหน่ง คุณปิดสถิติเหล่านี้ได้ในเกม ที่ การตั้งค่า แล้วเลือก แชร์สถิติการเล่นแบบไม่ระบุตัวตน การจัดการสถิติเหล่านี้ของ PostHog อยู่ภายใต้นโยบายความเป็นส่วนตัวของ PostHog

เด็ก

เราไม่เก็บรวบรวมข้อมูลที่ระบุตัวตนของผู้ใดได้ รวมถึงเด็ก ทั้งนี้ สถิติการเล่นเป็นแบบไม่ระบุตัวตน โฆษณาจะไม่เป็นโฆษณาเฉพาะบุคคลเลย และจำกัดเฉพาะโฆษณาที่ Google จัดระดับว่าเหมาะสมกับผู้ชมทั่วไป

เว็บไซต์นี้

เว็บไซต์นี้โฮสต์อยู่บน GitHub Pages ไม่ใช้คุกกี้และไม่มีระบบวิเคราะห์ข้อมูลของตัวเอง GitHub อาจบันทึกข้อมูลทางเทคนิค เช่น ที่อยู่ IP เพื่อดำเนินการให้บริการ ตามที่อธิบายไว้ในคำชี้แจงความเป็นส่วนตัวของ GitHub ตั้งแต่เวอร์ชัน 1.1 เกมยังอ่านไฟล์การตั้งค่าขนาดเล็กจากเว็บไซต์นี้เมื่อเริ่มทำงาน เพื่อให้แสดงโฆษณาน้อยลงหรือแจ้งว่ามีเวอร์ชันใหม่ได้ ตั้งแต่เวอร์ชัน 1.3 เกมยังดาวน์โหลดสวนใหม่จากเว็บไซต์นี้ด้วย เพื่อให้มีด่านใหม่ได้โดยไม่ต้องอัปเดต คำขอเหล่านี้ไม่มีข้อมูลใดเกี่ยวกับคุณ แต่เช่นเดียวกับการเข้าชมทุกครั้ง GitHub อาจบันทึกที่อยู่ IP ต้นทางของคำขอ คุณยังเล่นเกมในเบราว์เซอร์บนเว็บไซต์นี้ได้ด้วย ในกรณีนั้น เกมจะเก็บความคืบหน้าของคุณไว้ในพื้นที่จัดเก็บของเบราว์เซอร์บนอุปกรณ์ของคุณ และไม่ส่งสิ่งใดเกี่ยวกับตัวคุณหรือการเล่นของคุณไปยังเราหรือผู้อื่นใด
